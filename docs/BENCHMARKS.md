# Benchmarks

On 2026-10-02, `python scripts/benchmark_evaluator.py` ran 10,000 golden evaluations of 100 synthetic events each on Python 3.10.11, Windows 10 build 26300. One measured run took 0.5305 seconds (18,850.53 evaluations per second). Each iteration had 80 successful unique events, 20 duplicates, 0 rejected events, 0 retries, and a 364 byte JSON score report. The score was 1.0. Runtime and throughput vary by machine and concurrent load; this is a pure in-process evaluator benchmark, not API or distributed throughput.

On the same date, the containerized PySpark sample command in the README processed 5 rows in 12.705 seconds, wrote 2,492 bytes of Parquet, and reported 2 successful, 2 rejected, and 1 duplicate row. The counts reconciled. This five row run is a correctness fixture with startup overhead, not a throughput benchmark. See the generated `data-pipeline/reports/sample.json` (ignored by Git). Record future runs with hardware, software versions, input and outcome counts, wall time, output size, retries, command, and date.
